교구이음 웹앱 인수인계 가이드

담당 교사가 바뀔 때, 지금까지 쌓인 데이터(교사·물품·예약·사용기록·구입요청)와 교사 접속주소를 그대로 살린 채 새 담당자(또는 학교 공용 계정)에게 넘기는 방법입니다.

이 방식은 "이사" 입니다 — 데이터·접속주소(?s=…)는 그대로 두고, 저장소(스프레드시트) 소유자만 새 계정으로 바꿉니다. 교사들은 주소를 다시 받을 필요가 없습니다.

왜 "소유권 이전" 버튼은 안 되나요?

현재 시트 소유자가 개인 구글 계정(지메일이 아닌 네이버 등으로 만든 계정 포함)이고, 넘기려는 계정이 학교·교육청 조직 계정(@goedu.kr 등)이면, 구글은 개인↔조직 사이의 소유권 직접 이전을 정책적으로 막습니다. 그래서 "동일한 조직에 있는 사용자에게만 이전할 수 있습니다" 오류가 납니다. 우회 설정은 없으며, 아래의 사본 인계 방식으로 진행하면 됩니다.

🟡 가장 중요한 원칙: 새 시트가 정상 동작하는 것을 끝까지 확인하기 전에는 기존(원본) 시트를 절대 삭제·정리하지 마세요. 원본을 그대로 두면, 중간에 무슨 일이 생겨도 데이터가 사라지지 않습니다.
전체 순서
  1. 현 담당자 기존 시트를 새 담당자에게 편집자로 공유
  2. 새 담당자 시트 사본 만들기 (데이터·스크립트 통째로 복사)
  3. 새 담당자 사본에서 ① 처음 설정 / 연결 키 발급 + 권한 승인
  4. 새 담당자 사본 Apps Script 웹앱 새로 배포
  5. 새 담당자 ④ 접속 링크로 교구이음 앱 재연결
  6. 데이터·교사 링크 정상 확인 → 이상 없으면 원본 정리
  7. 교구이음 학교 계정(로그인) 인계

1단계현 담당자 기존 시트를 새 담당자에게 편집자로 공유

  1. 현재 데이터가 들어있는 학교 스프레드시트(예: 테스트3초 교구관리)를 엽니다.
  2. 우측 상단 공유를 클릭합니다.
  3. 새 담당자 계정(예: pbs1006@goedu.kr)을 입력하고 권한을 편집자로 설정한 뒤 보내기를 누릅니다.

이 단계는 새 담당자가 "사본 만들기"를 할 수 있도록 열어주는 것뿐입니다. 아직 아무 데이터도 옮겨지지 않습니다.

2단계새 담당자 시트 사본 만들기

  1. 새 담당자가 @goedu.kr 계정으로 구글에 로그인합니다.
  2. 1단계에서 공유받은 시트를 엽니다. (Gmail 또는 구글 드라이브 "공유 문서함"에서 찾을 수 있습니다.)
  3. 상단 메뉴 파일 → 사본 만들기를 클릭합니다.
  4. 저장 위치를 새 담당자(@goedu.kr)의 내 드라이브로 두고 사본 만들기를 누릅니다.
  5. 이름을 ○○초등학교 교구관리처럼 알아보기 쉽게 바꿉니다.

사본을 만들면 물품·교사 등 모든 데이터(셀 내용)와 Apps Script가 통째로 복사되고, 이 사본의 소유자는 새 담당자(@goedu.kr) 가 됩니다. 이것이 핵심입니다 — 이제 원본을 누가 지우든 사본은 영향받지 않는 독립 파일입니다.

단, 웹앱 배포 정보는 사본에 복사되지 않습니다. 그래서 3~4단계에서 사본에 대해 연결 키 발급과 웹앱 배포를 다시 해줘야 합니다.

3단계새 담당자 사본에서 ① 처음 설정 / 연결 키 발급

  1. 사본 시트 상단 메뉴에서 교구이음 → ① 처음 설정 / 연결 키 발급을 클릭합니다.

    메뉴가 안 보이면 새로고침(F5) 후 1~2초 기다리세요.

  2. 처음 한 번은 승인 필요 팝업이 뜹니다. 확인을 누릅니다.
    • "Google에서 확인하지 않은 앱"이 뜨면 → 화면 왼쪽 하단의 고급 → (안전하지 않음)으로 이동 클릭
    • 액세스 권한 화면이 뜨면 → 모두 선택 체크 → 계속 클릭
  3. 완료 팝업이 뜨면 확인을 눌러 닫습니다.
🟡 여기서 즉시 확인하세요: 사본 시트의 물품·교사 데이터가 그대로 남아있는지 눈으로 확인합니다. 만약 데이터가 비어 보이면 당황하지 말고 이 사본 창을 닫고 (원본은 그대로이므로) 2단계부터 다시 시도하세요. 원본을 건드리지 않았으니 손실은 없습니다.

4단계새 담당자 사본 Apps Script를 웹앱으로 새로 배포

  1. 사본 시트 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다. (새 탭)
  2. 오른쪽 위 배포 → 새 배포를 클릭합니다.
  3. 왼쪽 위 톱니바퀴(⚙️) → 웹 앱을 선택합니다.
  4. 설명란에 v1 입력.
  5. 다음 사용자 인증 정보로 실행: 나(새 담당자 계정) 선택.
  6. 액세스 권한이 있는 사용자: 모든 사용자 선택.

    "모든 사용자"라도 연결 키를 모르면 데이터에 접근할 수 없으니 안전합니다.

  7. 배포를 클릭합니다. (권한 승인 화면이 다시 나오면 동일하게 승인)
  8. 완료 화면의 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 메모장에 복사해 둡니다. 그리고 완료로 닫습니다.

이 URL은 사본 전용 새 주소입니다. 원본의 주소와 다릅니다. 다음 단계에서 이 새 주소로 앱을 재연결합니다.

5단계새 담당자 교구이음 앱 재연결

5-1. 사본에서 접속 링크 만들기

  1. 사본 시트 메뉴 교구이음 → ④ 우리 학교 접속 링크를 실행합니다.
  2. 표시되는 접속 링크를 복사합니다. (새 웹앱 주소 + 연결 키가 함께 들어있습니다.)

5-2. 교구이음 앱에서 연결 정보 교체

  1. 교구이음 앱(item-school.netlify.app)을 열고 상단 학교 관리자 로그인으로 기존 학교 계정에 로그인합니다.

    기존과 같은 학교 계정으로 로그인해야 교사 접속주소(?s=…)가 그대로 유지됩니다.

  2. 학교 계정 버튼(또는 연결 관리)에서 연결 설정 / 연결 정보 수정을 엽니다.
  3. 5-1에서 복사한 접속 링크(또는 새 웹앱 URL + 연결 키)를 붙여넣고 저장(연결)합니다.

이렇게 하면 같은 학교 계정·같은 교사 링크(?s=…)는 그대로 둔 채, 데이터를 읽고 쓰는 저장소만 "사본"으로 바뀝니다.

6단계정상 동작 확인 (이게 끝나기 전엔 원본 삭제 금지)

  • 앱(관리자 모드)에서 물품·교사 목록이 그대로 보인다.
  • 물품을 하나 수정/추가한 뒤, 사본 시트를 열어보면 그 변경이 반영되어 있다.
  • 교사용 주소 ?s=…로 접속하면 교사·물품이 정상적으로 보인다.
  • (가능하면) 다른 PC에서도 같은 데이터가 보인다.
🟡 위 항목이 모두 정상일 때에만, 원본(전임자 소유) 시트를 정리합니다. 확인 전에 원본을 지우면 되돌릴 수 없습니다.

원본 정리 방법 (확인 완료 후)

  • 안전하게: 전임자가 원본의 공유에서 자신 외 사람을 제거하고 그대로 보관(백업)하거나,
  • 완전히: 더 이상 필요 없다면 전임자가 원본을 휴지통으로 이동합니다. (되돌릴 수 없으니 6단계 확인 후에만)

7단계교구이음 학교 계정(로그인) 인계

위 1~6단계는 데이터 저장소(구글 시트)의 인계입니다. 여기에 더해, 앱에서 학교 관리자로 로그인하는 교구이음 학교 계정도 새 담당자가 쓸 수 있게 넘겨야 합니다.

방법 A — 같은 계정을 계속 사용 (권장)

  1. 기존 학교 계정으로 로그인한 상태에서 학교 설정 → "학교 관리자 계정 비밀번호 변경"으로 비밀번호를 새 담당자가 정한 값으로 바꿉니다.
  2. 로그인 이메일과 새 비밀번호를 새 담당자에게 전달합니다.

학교 계정은 학교 단위로 하나이므로, 계정을 새로 만들 필요 없이 비밀번호만 바꿔 넘기면 됩니다. 교사 접속주소(?s=…)도 바뀌지 않습니다.

새로 가입과 무엇이 다른가요?

이 가이드 (사본 인계)그냥 새로 가입
교사·물품·예약·사용기록그대로 보존모두 사라짐(재입력)
예약·사용 이력그대로복구 불가
교사 접속주소 ?s=…그대로 유지새 주소 → 전 교사 재배포
Apps Script 수고사본에 자동 복사 → 배포만스크립트 처음부터 설치

요약: 데이터를 살려야 한다면 이 가이드(사본 인계)가 맞고, 수고도 오히려 더 적습니다. 테스트용이라 데이터가 아무래도 좋다면 "새로 가입"이 더 단순합니다.

자주 생기는 문제와 해결

Q. 소유권 이전이 "같은 조직" 오류로 막힙니다.

A. 개인 계정 → 조직 계정으로는 구글이 막아 둔 정상 동작입니다. 이 가이드의 사본 인계로 진행하세요.

Q. 사본에서 ① 실행 후 데이터가 비어 보입니다.

A. 이 사본 창을 닫고(원본은 그대로) 2단계부터 다시 하세요. 원본을 건드리지 않았으니 손실은 없습니다.

Q. 재연결했더니 교사 화면이 0개로 보입니다.

A. 관리자 계정으로 로그인해 잠시 기다리면, 관리자 PC의 데이터가 사본 저장소로 자동 업로드됩니다. 그래도 비어 있으면 학교 설정에서 연결 정보가 새 웹앱 URL로 바뀌어 있는지 확인하세요.

Q. 교사 접속주소(?s=…)가 바뀌나요?

A. 같은 학교 계정으로 로그인해 연결 정보만 교체하면 주소는 그대로 유지됩니다. 교사들에게 새 링크를 다시 배포할 필요가 없습니다.

Q. 앞으로 이런 번거로움을 피하려면?

A. 처음 만들 때부터 학교 공용(조직) 계정으로 시트를 만들면, 담당자 변경 시 계정 접근 권한만 넘기면 되어 사본 인계가 필요 없습니다.
