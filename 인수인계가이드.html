교구이음 웹앱 인수인계 가이드

담당 교사가 바뀔 때, 지금까지 쌓인 데이터와 교사 접속주소를 그대로 살린 채 새 담당자에게 넘기는 방법입니다. 처음 만들 때 쓴 계정 종류에 따라 절차가 크게 다릅니다.

먼저 — 어떤 계정으로 시트를 만들었나요?

🟢 학교 공용 구글 계정

예: 학교 대표 Gmail, 행정실 공용 계정 등.
→ 경우 A (아주 간단 · 인계 절차 거의 없음)

🟠 담당 교사 개인 계정

예: 본인 개인 Gmail / 네이버로 만든 구글 계정 등.
→ 경우 B (사본 인계 필요)

모르겠으면, 그 스프레드시트를 열어 오른쪽 위 공유에서 "소유자"로 표시된 계정을 확인하세요. 학교 공용 계정이면 경우 A, 특정 교사 개인 계정이면 경우 B입니다.

경우 A학교 공용 구글 계정으로 만든 경우

인수인계 절차가 사실상 필요 없습니다. 시트·데이터·접속주소가 모두 학교 공용 계정에 그대로 들어 있으니, 계정 정보만 새 담당자에게 넘기면 끝입니다. 아무것도 옮기거나 다시 배포하지 않습니다.

  1. 학교 공용 구글 계정의 이메일·비밀번호를 새 담당자에게 전달합니다.
  2. 교구이음 앱의 학교 관리자 계정(로그인) 비밀번호를 새 담당자가 정한 값으로 바꿔 전달합니다.
    • 앱에서 학교 관리자 로그인 → 학교 설정 → "학교 관리자 계정 비밀번호 변경"
  3. 끝입니다. 데이터·교사 접속주소(?s=…)는 그대로이며, 교사들에게 링크를 다시 줄 필요도 없습니다.

그래서 처음 설정할 때부터 학교 공용 계정 사용을 권장합니다. 담당자가 바뀌어도 이렇게 계정만 넘기면 되기 때문입니다.

경우 B담당 교사 개인 계정으로 만든 경우

개인 계정은 퇴직·전근으로 계정이 사라지면 데이터와 웹앱도 함께 멈출 위험이 있습니다. 그래서 학교 공용 계정(또는 새 담당자 계정)으로 사본을 만들어 옮깁니다. 데이터와 교사 접속주소는 그대로 유지됩니다.

🟡 가장 중요한 원칙: 새 시트가 정상 동작하는 것을 끝까지 확인하기 전에는 기존(원본) 시트를 절대 삭제·정리하지 마세요. 원본을 그대로 두면 중간에 무슨 일이 생겨도 데이터가 사라지지 않습니다.

아래 3~5단계의 ① 처음 설정 / 웹앱 배포 / 접속 링크 절차는 처음 설정 가이드와 동일합니다. 처음 설정해 본 분이라면 익숙한 화면 그대로입니다.

1단계현 담당자 기존 시트를 새 계정에 편집자로 공유

  1. 현재 데이터가 들어있는 학교 스프레드시트를 엽니다.
  2. 오른쪽 위 공유를 클릭합니다.
  3. 새로 소유할 계정(학교 공용 계정 또는 새 담당자 계정)을 입력하고 권한을 편집자로 설정한 뒤 보내기를 누릅니다.

이 단계는 사본을 만들 수 있도록 열어주는 것뿐입니다. 아직 데이터는 아무것도 옮겨지지 않습니다.

2단계새 계정 시트 사본 만들기

  1. 새로 소유할 계정(학교 공용 계정 권장)으로 구글에 로그인합니다.
  2. 1단계에서 공유받은 시트를 엽니다. (Gmail 또는 구글 드라이브 "공유 문서함"에서 찾을 수 있습니다.)
  3. 상단 메뉴 파일 → 사본 만들기를 클릭합니다.
  4. 저장 위치를 이 계정의 내 드라이브로 두고 사본 만들기를 누릅니다.
  5. 이름을 ○○초등학교 교구관리처럼 알아보기 쉽게 바꿉니다.

사본을 만들면 모든 데이터와 Apps Script가 통째로 복사되고, 사본의 소유자는 이 계정이 됩니다. 이제 원본을 누가 지워도 사본은 영향받지 않는 독립 파일입니다.

단, 웹앱 배포 정보는 사본에 복사되지 않습니다. 그래서 3~5단계를 사본에 대해 다시 해줍니다.

3단계새 계정 '교구이음' 메뉴에서 ① 처음 설정 + 권한 승인

  1. 사본 시트 상단 메뉴에서 교구이음 → ① 처음 설정 / 연결 키 발급을 클릭합니다.

    메뉴가 보이지 않으면 새로고침(F5)를 하고 1~2초 정도 기다려주세요.

  2. 처음 한 번은 승인 필요 팝업이 뜹니다. 확인을 클릭합니다.
    • "Google에서 확인하지 않은 앱"이 뜨면 → 화면 왼쪽 하단의 고급 클릭 → 교구이음 시트(으)로 이동(안전하지 않음) 클릭
    • 액세스 권한 선택 화면이 뜨면 → 모두 선택 체크 → 하단 계속 클릭
  3. 잠시 후 처음 설정 완료 팝업이 뜨면 확인을 눌러 닫습니다.
🟡 여기서 즉시 확인하세요: 사본 시트의 물품·교사 데이터가 그대로 남아있는지 눈으로 확인합니다. 비어 보이면 이 사본 창을 닫고 (원본은 그대로이므로) 2단계부터 다시 하세요. 손실은 없습니다.

4단계새 계정 Apps Script를 웹앱으로 배포

  1. 사본 시트 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다. (새 탭으로 열림)
  2. Apps Script 화면 오른쪽 위 배포 버튼 → 새 배포를 클릭합니다.
  3. 왼쪽 위 톱니바퀴(⚙️) → 웹 앱을 선택합니다.
  4. 설명란에 v1을 입력합니다.
  5. 다음 사용자 인증 정보로 실행: 나(본인 계정) 선택.
  6. 액세스 권한이 있는 사용자: 모든 사용자 선택.

    "모든 사용자"를 선택해도 스프레드시트가 공개되는 게 아닙니다. 연결 키를 모르는 사람은 데이터에 접근할 수 없습니다.

  7. 배포를 클릭합니다. (권한 승인 화면이 다시 나오면 동일하게 고급 → 안전하지 않음 → 허용)
  8. 완료 화면에 웹 앱 URL(https://script.google.com/macros/s/.../exec)이 나타납니다. 이 URL을 메모장에 복사해 두세요.

    ⚠️ 이 웹 앱 URL을 교구이음 앱에 직접 붙여넣으면 안 됩니다. URL에는 연결 키(apiKey)가 없어 인증 오류가 납니다. 반드시 아래 5단계의 시트 메뉴(④ 접속 링크)를 통해 완성된 접속 링크를 만들어야 합니다.

  9. 완료를 눌러 창을 닫고 사본 스프레드시트 탭으로 돌아갑니다.

이 웹 앱 URL은 사본 전용 새 주소입니다. 원본 주소와 다릅니다. 다음 단계에서 이 주소로 앱을 재연결합니다.

5단계새 계정 '④ 접속 링크'로 교구이음 앱 재연결

⚠️ 웹 앱 URL ≠ 접속 링크. 4단계의 웹 앱 URL에는 연결 키가 없어 앱에 직접 쓸 수 없습니다. 이 단계에서 시트 메뉴가 웹 앱 URL + 연결 키를 합쳐 완성된 접속 링크를 만들어 줍니다. 그 완성된 링크를 앱에 붙여넣으세요.

  1. 사본 시트 메뉴 교구이음 → ④ 우리 학교 접속 링크를 클릭합니다.
  2. URL 입력창이 뜨면 4단계에서 복사해 둔 웹 앱 URL(/exec로 끝나는 주소)을 붙여넣고 확인을 누릅니다.
  3. 팝업에 완성된 접속 링크(https://item-school.netlify.app/?d=...&k=연결키)가 나타납니다. [주소 복사] 버튼을 눌러 이 링크를 복사합니다.
  4. 교구이음 웹페이지(item-school.netlify.app)로 돌아가 학교 관리자 로그인으로 기존 학교 계정에 로그인합니다.

    반드시 같은 학교 계정으로 로그인해야 교사 접속주소(?s=…)가 그대로 유지됩니다.

  5. 연결 설정 / 연결 정보 수정의 '접속 링크 붙여넣기' 칸에 3번에서 복사한 링크를 붙여넣고 [연결하기]를 누릅니다.
  6. "연결됐습니다!" 메시지가 나오면 성공입니다.

이렇게 하면 같은 학교 계정·같은 교사 링크(?s=…)는 그대로 둔 채, 데이터를 읽고 쓰는 저장소만 '사본'으로 바뀝니다.

6단계정상 동작 확인 → 이상 없으면 원본 정리

  • 앱(관리자 모드)에서 물품·교사 목록이 그대로 보인다.
  • 물품을 하나 수정/추가한 뒤 사본 시트를 열어보면 그 변경이 반영되어 있다.
  • 교사용 주소 ?s=…로 접속하면 교사·물품이 정상적으로 보인다.
🟡 위 항목이 모두 정상일 때에만, 원본(전임자 소유) 시트를 정리합니다. 확인 전에 원본을 지우면 되돌릴 수 없습니다.

확인이 끝나면 전임자가 원본을 휴지통으로 이동하거나, 백업으로 보관해도 됩니다.

7단계학교 관리자 계정(로그인) 비밀번호 인계

위 1~6단계는 데이터 저장소(구글 시트)의 인계입니다. 마지막으로 앱 로그인용 학교 계정도 넘깁니다.

  1. 기존 학교 계정으로 로그인한 상태에서 학교 설정 → "학교 관리자 계정 비밀번호 변경"으로 비밀번호를 새 담당자가 정한 값으로 바꿉니다.
  2. 로그인 이메일과 새 비밀번호를 새 담당자에게 전달합니다.

학교 계정은 학교 단위로 하나이므로, 새로 만들 필요 없이 비밀번호만 바꿔 넘기면 됩니다. 교사 접속주소도 그대로입니다.

사본 인계(경우 B) vs 새로 가입

사본 인계 (경우 B)그냥 새로 가입
교사·물품·예약·사용기록그대로 보존모두 사라짐(재입력)
예약·사용 이력그대로복구 불가
교사 접속주소 ?s=…그대로 유지새 주소 → 전 교사 재배포
Apps Script 수고사본에 자동 복사 → 배포만스크립트 처음부터 설치

데이터를 살려야 하면 사본 인계가 맞고 수고도 더 적습니다. 테스트용이라 데이터가 아무래도 좋다면 새로 가입이 더 단순합니다.

자주 생기는 문제

Q. 재연결했더니 교사 화면이 0개로 보입니다.

A. 관리자 계정으로 로그인해 잠시 기다리면, 관리자 PC의 데이터가 사본 저장소로 자동 업로드됩니다. 그래도 비어 있으면 학교 설정에서 연결 정보가 새 웹앱 URL로 바뀌어 있는지 확인하세요.

Q. 교사 접속주소(?s=…)가 바뀌나요?

A. 같은 학교 계정으로 로그인해 연결 정보만 교체하면 주소는 그대로 유지됩니다. 교사들에게 새 링크를 다시 줄 필요가 없습니다.

Q. 앞으로 이런 번거로움을 피하려면?

A. 처음 만들 때부터 학교 공용(조직) 계정으로 시트를 만들면, 담당자 변경 시 경우 A처럼 계정만 넘기면 되어 사본 인계가 필요 없습니다.
