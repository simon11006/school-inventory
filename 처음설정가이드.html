교구이음 처음 설정 가이드

이 문서는 한 번도 Apps Script를 만져본 적 없는 분도 따라 할 수 있도록 순서대로 안내합니다. 모든 단계를 위에서 아래로 그대로 따라 하세요.

준비물: 학교 관리자용 Google 계정(학교 공용 또는 개인 계정)

스프레드시트와 Apps Script는 담당자 개인 계정보다 학교 공용 계정으로 만드는 것을 권장합니다. 개인 계정으로 만든 경우 담당자 변경·퇴직 시 소유권을 이전하는 절차가 필요합니다.

전체 순서 (4단계)
  1. 학교용 스프레드시트 사본 만들기
  2. '교구이음' 메뉴 → ① 처음 설정 실행 + 권한 승인
  3. Apps Script를 웹앱으로 배포 → URL 복사
  4. '④ 우리 학교 접속 링크' 복사 → 교구이음 앱 연결 칸에 붙여넣기

1단계학교용 스프레드시트 사본 만들기

  1. 학교 관리자용 Google 계정(학교 공용 또는 개인 계정)으로 브라우저에 로그인합니다.
  2. 아래 학교용 시트 만들기 버튼을 클릭합니다.

    ▶ 학교용 시트 만들기

  3. 구글 드라이브가 "문서를 복사하시겠습니까?" 화면을 보여줍니다. 사본 만들기를 클릭합니다.
  4. 학교 관리자용 계정 Google Drive에 새 스프레드시트가 자동으로 생성되어 열립니다.
  5. 교구이음 마스터시트의 사본이라고 적인 스프레드시트 이름을 ○○초등학교 교구관리처럼 학교명이 포함된 알아보기 쉬운 이름으로 바꿉니다.

이 사본 시트가 학교 데이터의 저장소가 됩니다. 모든 교사 PC가 이 시트를 통해 같은 데이터를 공유합니다.

담당자 개인 계정으로 만든 경우, 담당자가 바뀔 때 스프레드시트 소유권과 웹 앱 배포 권한을 새 담당자에게 넘겨야 합니다. 학교 공용 계정으로 만들면 계정 접근 권한만 인계받아 기존 데이터를 그대로 이어 사용할 수 있습니다.

2단계'교구이음' 메뉴에서 처음 설정 실행 + 권한 승인

  1. 1단계에서 만든 사본 시트 상단 메뉴에서 교구이음 → ① 처음 설정 / 연결 키 발급을 클릭합니다.

    메뉴가 보이지 않으면 새로고침(F5)를 하고 1~2초 정도 기다려주세요.

  2. 처음 한 번은 승인 필요 팝업이 뜹니다. 확인을 클릭합니다.
    • "Google에서 확인하지 않은 앱"이 뜨면 → 화면 왼쪽 하단의 고급 클릭 → 교구이음 시트(으)로 이동(안전하지 않음) 클릭
    • 액세스 권한 선택 화면이 뜨면 → 모두 선택 체크 → 하단 계속 클릭
  3. 잠시 후 처음 설정 완료 팝업이 뜨면 확인을 눌러 닫은 뒤, 교구이음 설정 가이드 3단계를 진행하세요.

연결 키는 다음 단계에서 자동으로 링크에 포함되므로 따로 복사해 둘 필요가 없습니다.

3단계Apps Script를 웹앱으로 배포

  1. 사본 시트 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다. (새 탭으로 열림)
  2. Apps Script 화면 오른쪽 위 배포 버튼 → 새 배포를 클릭합니다.
  3. 왼쪽 위 톱니바퀴(⚙️) → 웹 앱을 선택합니다.
  4. 설명란에 v1을 입력합니다.
  5. 다음 사용자 인증 정보로 실행: 나(본인 계정) 선택.
  6. 액세스 권한이 있는 사용자: 모든 사용자 선택.

    "모든 사용자"를 선택해도 스프레드시트가 공개되는 게 아닙니다. 연결 키를 모르는 사람은 데이터에 접근할 수 없습니다.

  7. 배포를 클릭합니다.
  8. 완료 화면에 웹 앱 URL(https://script.google.com/macros/s/.../exec)이 나타납니다. 이 URL을 메모장에 복사해 두세요. 다음 단계에서 붙여넣어야 합니다.
  9. 완료를 눌러 창을 닫습니다.

웹 앱 URL은 4단계에서 반드시 필요합니다. 지금 바로 메모장에 저장해 두세요.

4단계'④ 우리 학교 접속 링크' 복사 → 교구이음 앱에 붙여넣기

  1. 사본 시트로 돌아가 교구이음 → ④ 우리 학교 접속 링크를 클릭합니다.
  2. URL 입력창이 뜨면 3단계에서 복사한 웹 앱 URL(/exec로 끝나는 주소)을 붙여넣고 확인을 누릅니다.
  3. 팝업에 접속 링크 주소(https://item-school.netlify.app/?d=...&k=...)가 표시됩니다. 복사 버튼을 눌러 주소를 복사합니다.

    "▶ 우리 학교 앱 열기" 버튼은 지금 누르지 마세요. 주소만 복사한 뒤 아래 4번 단계로 이동하세요.

  4. 교구이음 웹페이지(item-school.netlify.app)로 돌아갑니다. 학교 계정 로그인 후 표시되는 연결 설정 화면의 '접속 링크 붙여넣기' 칸에 방금 복사한 주소를 붙여넣고 [연결하기] 버튼을 누릅니다.
  5. 연결이 완료되면 설정 완료 화면이 나타나며 교사 초대 주소가 표시됩니다. [닫기]를 눌러 팝업을 닫습니다.
  6. 상단 오른쪽 학교 설정 버튼을 클릭합니다. 학교 설정 화면에서 아래 항목을 입력한 뒤 [저장]을 누릅니다.
    • 학교명 입력
    • 교사 추가: 사용할 교사 이름을 모두 추가합니다.
    • 물품실 추가: 체육실·과학실 등 물품실을 추가합니다.
    • 물품실 담당자 지정: 각 물품실에 담당 교사를 지정합니다.

    저장 버튼을 누르면 기본 설정이 완료됩니다.

  7. 실별 담당자에게 이 설정 가이드를 안내해 물품 등록을 진행하도록 합니다. 전체 교사에게는 5번에서 확인한 교사 초대 주소(.../?s=짧은코드)를 학교 내부 메신저로 공유하면 사용 준비가 완료됩니다.

연결 후 앱에 표시되는 교사 초대 주소(.../?s=짧은코드)가 교사용 링크입니다. 교사들에게 이 주소를 공유하면 별도 설정 없이 바로 접속할 수 있습니다.

접속 링크와 교사 초대 주소에는 연결 키가 포함됩니다. 학교 내부 메신저로만 공유하고 외부 사이트·SNS·이메일 등에 올리지 마세요.

설정 완료 후 할 일

교사들에게 링크 공유

연결 완료 후 앱에 표시되는 교사 초대 주소(.../?s=짧은코드)를 카카오톡·네이버 밴드 등 학교 내부 메신저로 공유하세요.

교사가 이 주소를 클릭하면 자동으로 학교 데이터가 연결되어 바로 사용할 수 있습니다. 교사는 가입·로그인이 필요 없습니다.

동기화 동작

  • 물품 등록·예약·반납 등 변경이 일어나면 즉시 스프레드시트에 자동 저장
  • 다른 교사의 변경은 최대 20초 안에 자동 반영

마지막 점검표

  • 학교명·교사·물품실이 학교 설정에 채워져 있다.
  • 앱에 표시된 교사 초대 주소(?s=…)를 학교 내부 메신저로만 공유했다.
  • 다른 교사 PC에서도 링크로 접속해 같은 데이터가 보인다.
  • 한 PC에서 예약을 만들었을 때, 다른 PC에서 20초 안에 자동 반영된다.
  • 웹 앱 URL을 메모장 등 안전한 곳에 보관해 두었다.

자주 생기는 문제와 해결

링크를 클릭했는데 연결이 안 됩니다 (CORS 오류)

웹 앱 URL 입력 시 /exec로 끝나는 주소를 정확히 붙여넣었는지 확인하세요. Apps Script → 배포 → 배포 관리에서 URL을 다시 확인하고, 액세스 권한이 있는 사용자가 모든 사용자로 되어 있는지 확인하세요.

"setupInventorySpreadsheet를 먼저 실행하세요"가 뜹니다

사본 시트로 돌아가 교구이음 → ① 처음 설정 / 연결 키 발급을 다시 실행하세요.

웹 앱 URL을 잃어버렸습니다

Apps Script → 배포 → 배포 관리를 열면 기존 URL을 다시 확인할 수 있습니다.

연결 키가 유출된 것 같습니다

시트에서 교구이음 → 연결 키 새로 발급(재발급)을 실행하세요. 이후 ④ 우리 학교 접속 링크를 다시 실행해 새 링크를 만든 뒤, 교구이음 앱에 로그인해 [연결 정보 수정]에서 새 링크를 붙여넣으면 교사 초대 주소가 자동으로 갱신됩니다.

다른 교사 화면에 내 변경이 안 보입니다

최대 20초 안에 반영되는지 확인하세요. 교사가 교사 초대 링크로 접속했는지 확인합니다. 일반 주소로 접속하면 동기화 설정이 누락될 수 있습니다.

'교구이음' 메뉴가 시트에 안 보입니다

시트를 새로고침(F5)하세요. 처음 열 때 메뉴가 만들어지는 데 몇 초 걸릴 수 있습니다.

한 학교의 사용 가능 인원

이 시스템은 학교 단위로 분리되어 있어 학교마다 자기 한도를 사용합니다.

계정 종류일일 한도예상 동시 사용 교사
개인 Gmail 계정약 20,000회약 100~300명
학교/교육청 Workspace 계정약 100,000회약 500~1,500명

교사 1인당 평균 30분 사용 기준입니다. 실제로는 이보다 더 많은 인원도 무리 없이 운영할 수 있습니다.

추가 도움이 필요하면 학교 정보 담당자에게 문의하세요.
