교구이음 처음 설정 가이드

이 문서는 한 번도 Apps Script를 만져본 적 없는 분도 따라 할 수 있도록 순서대로 안내합니다. 모든 단계를 위에서 아래로 그대로 따라 하세요.

준비물: 학교 공용 Google 계정 한 개, 인터넷이 되는 컴퓨터 한 대. 처음 관리자 PIN은 1234입니다. 설정이 끝나면 반드시 PIN을 바꾸세요.

스프레드시트와 Apps Script는 담당자 개인 계정보다 학교 공용 계정으로 만드는 것을 권장합니다. 개인 계정으로 만들면 담당자 변경이나 퇴직 시 소유권·웹앱 관리 권한 인계가 어려워질 수 있습니다.

전체 순서
  1. 학교 기본 정보 입력
  2. 학교용 스프레드시트 사본 만들기 (링크 한 번 클릭)
  3. 시트 상단 ’교구이음’ 메뉴 → 처음 설정 실행 (연결 키 자동 발급)
  4. Apps Script를 웹앱으로 배포 (URL 발급)
  5. 앱에 URL과 연결 키 입력
  6. 연결 진단 → 현재 데이터 올리기
  7. 실시간 자동 동기화 켜기
  8. 다른 교사 PC에서 같은 주소로 접속

1단계학교 기본 정보 입력

  1. 오른쪽 위 학교 설정 버튼을 누릅니다.
  2. 아래 항목을 차례대로 입력합니다.
    • 학교명: 예) ○○초등학교
    • 교사 목록: + 교사 추가로 학교의 모든 교사 이름을 먼저 등록합니다. 이름이 곧 예약자 정보가 됩니다.
    • 물품실: 교사 목록을 다 입력한 뒤 + 물품실 추가로 학교에 실제 있는 물품실을 등록합니다. 예) 체육실, 과학실, 컴퓨터실, 미술실, 방송실.
    • 물품실별 담당자: 물품실 행의 드롭다운에서 위에서 입력한 교사 이름을 선택하고 담당자 PIN(4자리 이상)을 지정합니다. 담당자는 자기 물품실만 관리할 수 있습니다.
    • 관리자 PIN: 현재 PIN(1234)을 입력하고 새 PIN(4자리 이상)을 입력해 변경합니다.
  3. 아래 저장을 누릅니다.

이 시점까지는 이 브라우저(localStorage)에만 저장됩니다. 다른 컴퓨터와 공유하려면 다음 단계의 Google Spreadsheet 연동이 반드시 필요합니다.

2단계학교용 스프레드시트 사본 만들기 (링크 한 번 클릭)

  1. 학교 공용 Google 계정으로 브라우저에 로그인합니다. (담당자 개인 계정보다 인수인계가 쉽고, 교육청 Workspace 계정은 호출 한도도 높아 권장)
  2. 아래 학교용 시트 만들기 링크를 클릭합니다.

    ▶ 학교용 시트 만들기

  3. 구글 드라이브가 "문서를 복사하시겠습니까?" 화면을 보여줍니다. 사본 만들기를 클릭합니다.
  4. 잠시 후 학교 계정의 Google Drive에 새 스프레드시트가 자동으로 생성되어 열립니다. 이 시트 안에는 교구이음 운영에 필요한 코드와 시트 구조가 이미 포함되어 있습니다.
  5. 왼쪽 위 시트 이름(예: 교구이음 마스터시트의 사본)을 클릭해서 ○○초등학교 교구관리처럼 알아보기 쉽게 바꿉니다.

이 사본 시트가 학교 데이터의 진짜 저장소가 됩니다. 다른 교사 PC들은 이 시트를 통해 같은 데이터를 공유합니다.

담당자 개인 계정으로 만든 경우, 담당자가 바뀔 때 스프레드시트 소유권과 웹 앱 배포 권한을 새 담당자에게 넘겨야 합니다. 학교 공용 계정으로 만들면 새 담당자는 계정 접근 권한만 인계받아 기존 데이터를 그대로 이어 사용할 수 있습니다.

3단계’교구이음’ 메뉴에서 처음 설정 실행 (연결 키 자동 발급)

  1. 2단계에서 만든 사본 시트의 상단 메뉴 줄을 봅니다. 파일 / 수정 / 보기 ... 옆에 ‘교구이음’ 메뉴가 추가되어 있습니다.

    메뉴가 보이지 않으면 시트를 한 번 새로고침(F5)하세요. 처음 열 때 메뉴가 자동으로 만들어지는 데 몇 초 걸릴 수 있습니다.

  2. 교구이음 → ① 처음 설정 / 연결 키 발급을 클릭합니다.
  3. 처음 한 번은 승인 필요 팝업이 뜹니다.
    • 권한 검토 클릭
    • 학교 Google 계정 선택
    • "Google에서 확인하지 않은 앱"이라고 나오면 → 왼쪽 아래 고급 → (스크립트 이름)(으)로 이동(안전하지 않음) 클릭
    • 액세스 항목 요청 시 모두 선택 클릭 후 하단의 계속 버튼 클릭
    • 권한 목록에서 허용 클릭
  4. 승인이 끝나면 잠시 후 자동으로 ”처음 설정 완료” 다이얼로그가 뜨고, 회색 박스 안에 연결 키(API Key)가 표시됩니다. 박스를 클릭해서 키 전체를 선택한 뒤 Ctrl+C로 복사해 메모장에 보관합니다.
  5. 연결 키를 메모장에 보관한 뒤 다이얼로그를 닫고 5단계로 넘어갑니다.

연결 키를 잃어버렸을 때는 교구이음 → ② 연결 키 다시 보기를 누르면 같은 키가 다시 나타납니다. 유출이 의심될 때만 연결 키 새로 발급(재발급)을 사용하세요. (재발급 후 모든 교사 PC의 키도 새로 입력해야 합니다.)

연결 키는 외부에 공개하면 안 됩니다. 메일·메신저로 보낼 때는 학교 내부 채널만 이용하세요.

4단계Apps Script를 웹앱으로 배포 (URL 발급)

3단계의 ”처음 설정 완료” 다이얼로그 아래쪽 안내(다음 단계: 웹앱으로 배포)와 같은 내용입니다. 화면을 보면서 그대로 따라 하셔도 됩니다.

  1. 사본 시트 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭해 편집기를 엽니다. (새 탭으로 열림)
  2. Apps Script 화면 오른쪽 위 배포 버튼을 누르고 새 배포를 클릭합니다.
  3. 왼쪽 위 톱니바퀴(⚙️) 유형 선택을 누르고 웹 앱을 고릅니다.
  4. 설명: 교구이음 API라고 입력합니다.
  5. 다음 사용자로 실행: 나 그대로 둡니다.
  6. 액세스 권한이 있는 사용자: 모든 사용자를 선택합니다.

    "모든 사용자"를 선택해도 스프레드시트가 공개되는 게 아닙니다. 연결 키를 모르는 사람은 데이터에 접근할 수 없습니다.

  7. 아래쪽 배포 버튼을 누릅니다.
  8. 잠시 후 웹 앱 URL이 나타납니다. https://script.google.com/macros/s/.../exec 형식입니다. 이 URL을 메모장에 복사해 둡니다.
  9. 완료를 눌러 창을 닫습니다.

이 URL과 연결 키는 학교 데이터에 접근할 수 있는 열쇠입니다. 외부에 공개하지 마세요.

5단계앱에 URL과 연결 키 입력

  1. 1단계에서 열어둔 교구이음 앱 화면으로 돌아갑니다.
  2. 관리자 모드 > 학교 설정을 다시 엽니다.
  3. 저장소 연결 섹션을 찾습니다.
  4. 저장 방식을 이 브라우저에만 저장 에서 Google Spreadsheet 연동 준비로 바꿉니다.
  5. 연결 키: 3단계에서 복사한 apiKey 값을 붙여넣습니다.
  6. Apps Script 웹앱 URL: 4단계에서 복사한 URL을 붙여넣습니다.
  7. 자동 동기화: 처음 연결 시에는 수동으로만 실행을 선택합니다. (이상이 없으면 7단계에서 자동 모드로 바꿉니다.)
  8. 아래 저장을 누릅니다. (모달이 닫히지 않고 그대로 유지됩니다.)

6단계연결 진단 → 현재 데이터 올리기

  1. 5단계에서 저장 후 모달이 열린 상태에서 바로 저장소 연결 섹션 아래의 연결 진단 버튼을 누릅니다.
  2. 아래 표가 모두 정상으로 표시되면 성공입니다.
    시트의미
    items물품 목록 저장
    reservations예약·반납 저장
    logs사용 기록 저장
    teachers교사 목록 저장
    locations물품실 목록 저장
    settings학교명, PIN, 담당자 정보 저장
  3. 이상이 없으면 현재 데이터 올리기를 누릅니다. 1단계에서 입력한 학교명·교사·물품실 정보가 스프레드시트로 올라갑니다.
  4. 스프레드시트 탭으로 가서 새로고침하면 시트별로 데이터가 채워진 게 보입니다.

진단이 실패하면

  • 연결 키가 올바르지 않습니다: 처음 설정 완료 다이얼로그에서 표시된 apiKey를 다시 확인하세요. 앞뒤 공백이 들어갔을 수 있습니다.
  • 웹앱 URL 응답이 없습니다: 4단계의 URL이 /exec로 끝나는지 확인하세요.
  • setupInventorySpreadsheet를 먼저 실행하세요: 교구이음 메뉴 → ① 처음 설정 / 연결 키 발급을 실행하지 않은 상태입니다. 사본 시트로 돌아가 해당 메뉴를 다시 실행하세요.
  • 권한이 없습니다: 4단계 배포 시 액세스 권한을 다시 확인하세요.

7단계실시간 자동 동기화 켜기

여기까지 오면 한 PC에서 정상 작동합니다. 이제 여러 교사 PC가 실시간으로 같은 데이터를 보도록 설정합니다.

  1. 학교 설정을 다시 엽니다.
  2. 자동 동기화 항목을 저장 후 원격에 자동 올리기로 바꿉니다.
  3. 아래 저장을 누릅니다.

이 모드의 동작

  • 물품 등록·예약·반납 등 변경이 일어나면 즉시 스프레드시트에 자동 저장
  • 웹앱이 켜져 있는 동안 20초마다 다른 PC의 변경을 자동으로 가져와 화면을 갱신
  • 다른 탭/창을 보고 있을 때는 자동으로 일시정지 (호출 한도 절약)
  • 다시 화면으로 돌아오면 즉시 한 번 동기화 후 20초 폴링 재개

이 동작은 추가 설정 없이 자동으로 작동합니다. 자동 동기화를 저장 후 원격에 자동 올리기 또는 앱 시작 시 원격 데이터 확인으로 켜두기만 하면 됩니다.

완전한 실시간이 아닌 점

다른 교사가 예약하면 내 화면에 최대 20초 안에 반영됩니다. 학교 물품 예약 용도에는 충분한 속도이며, 동시 예약 충돌은 자동으로 막힙니다.

8단계다른 교사 PC에서 같은 주소로 접속

관리자가 할 일: 교사 초대 링크 만들기

  1. 학교 설정을 엽니다.
  2. 아래쪽 교사 초대 링크 섹션을 찾습니다.
  3. 저장소 연결(URL, 연결 키)이 설정되어 있으면 자동으로 링크가 생성됩니다.
  4. 링크 복사 버튼을 누릅니다.
  5. 복사된 링크를 카카오톡, 네이버 밴드 등 학교 내부 메신저로 교사들에게 공유합니다.

이 링크에는 연결 키와 URL이 포함되어 있어서 교사들이 별도 설정 없이 바로 사용할 수 있습니다.

교사가 할 일

  1. 관리자가 공유한 링크를 클릭합니다. 끝입니다!
  2. 이 링크를 즐겨찾기(북마크)에 추가합니다.
  3. 이후부터는 즐겨찾기에서 열면 됩니다.

자주 묻는 질문

상황대처
처음 열었는데 데이터가 안 보여요20초 안에 자동으로 채워집니다. 잠시 기다리세요.
브라우저 캐시를 지웠어요교사 초대 링크로 다시 접속하면 됩니다.
새 컴퓨터에서 쓰고 싶어요교사 초대 링크로 접속하면 됩니다.
관리자가 교사 초대 링크를 잃어버렸어요학교 설정 → 교사 초대 링크 섹션에서 다시 확인하거나 복사할 수 있습니다.

교사 초대 링크에는 연결 키가 포함되어 있습니다. 학교 내부 메신저로만 공유하고 외부 사이트나 SNS에 올리지 마세요.

브라우저 캐시를 지우면 모든 연결 설정이 초기화됩니다. 관리자는 반드시 Apps Script 웹앱 URL, 연결 키, 교사 초대 링크를 학교 내부 메신저나 메모장 등 별도 장소에 보관해 두세요. 분실 시 학교 설정에서 URL과 연결 키를 다시 입력해야 복구할 수 있습니다.

마지막 점검표

  • 관리자 PIN을 1234에서 학교 운영용 PIN으로 변경했다.
  • 물품실마다 담당자와 담당자 PIN을 지정했다.
  • Google 스프레드시트 연결 진단이 모두 정상으로 표시된다.
  • 현재 데이터 올리기를 한 번 실행했다.
  • 자동 동기화를 저장 후 원격에 자동 올리기로 설정했다.
  • 다른 교사 PC에서도 교사 초대 링크로 접속해 같은 데이터가 보인다.
  • 한 PC에서 예약을 만들었을 때, 다른 PC에서 20초 안에 자동 반영된다.
  • 웹앱 URL과 연결 키는 학교 내부 채널로만 공유 중이다.

자주 생기는 문제와 해결

"연결 키가 올바르지 않습니다"가 뜹니다

처음 설정 완료 다이얼로그에서 표시된 apiKey를 다시 복사해 학교 설정 → 저장소 연결의 연결 키 칸에 붙여넣어 보세요. 앞뒤 공백 주의.

"setupInventorySpreadsheet를 먼저 실행하세요"가 뜹니다

시트 상단 교구이음 메뉴 → ① 처음 설정 / 연결 키 발급을 실행하지 않은 상태입니다. 사본 시트로 돌아가 해당 메뉴를 다시 실행하세요.

웹앱 URL을 잃어버렸습니다

Apps Script 화면에서 배포 > 배포 관리를 누르면 기존 URL이 그대로 보입니다.

연결 키가 유출된 것 같습니다

Apps Script에서 setupInventorySpreadsheet를 다시 실행하면 새 연결 키가 발급됩니다. 모든 PC의 연결 키를 새 값으로 교체하세요.

다른 교사 화면에 내 변경이 안 보입니다

20초 안에 반영되는지 확인하세요. 그 이상 걸리면 교사 초대 링크로 접속했는지 확인합니다. 일반 주소로 접속하면 동기화 설정이 누락될 수 있습니다.

관리자 PIN을 잊었습니다

스프레드시트의 settings 시트에서 adminPin 행을 찾아 새 PIN으로 직접 수정한 뒤, 앱에서 스프레드시트에서 가져오기를 실행하세요.

교사 초대 링크로 접속 시 화면이 안 열립니다 (또는 동기화 실패)

앱에 입력한 웹앱 URL이 잘못되었을 수 있습니다. https://script.google.com/macros/s/.../exec 형태로 /exec로 끝나야 정상입니다. 만약 /macros/library/d/... 같은 형태의 주소를 넣었다면 CORS 에러가 발생해 다른 교사들이 접속할 수 없으니, 배포 관리에서 정확한 웹앱 URL을 다시 복사해 설정하세요.

한 학교의 사용 가능 인원

이 시스템은 학교 단위로 분리되어 있어 학교마다 자기 한도를 사용합니다. 한 학교 기준 일일 호출 한도는 다음과 같습니다.

계정 종류일일 한도예상 동시 사용 교사
개인 Gmail 계정약 20,000회약 100~300명
학교/교육청 Workspace 계정약 100,000회약 500~1,500명

교사 1인당 평균 30분 사용 기준입니다. 모든 교사가 항상 켜둘 일은 거의 없으므로 실제로는 이보다 더 많은 인원도 무리 없이 운영할 수 있습니다.

Google Spreadsheet 연동 단계에서만 인터넷과 학교 Google 계정이 필요합니다. 추가 도움이 필요하면 학교 정보 담당자에게 문의하세요.
