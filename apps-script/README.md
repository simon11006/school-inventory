# 교구이음 Apps Script (스프레드시트 백엔드)

이 폴더의 `Code.gs`는 각 학교 Google 스프레드시트에 들어가는 Apps Script 백엔드 코드입니다.
교구이음 웹앱은 이 스크립트가 배포한 웹앱 URL(`/exec`) + 연결 키로 데이터를 읽고/씁니다.

> ⚠️ 이 파일은 **저장소 보관/버전관리용 사본**입니다. 실제로 동작하는 코드는 각 학교
> 스프레드시트의 **확장 프로그램 → Apps Script** 안에 있습니다. 코드를 바꾸면 그쪽에도
> 반영(붙여넣기 + 재배포)해야 합니다.

## 데이터 구조
- `TABLES` 가 각 시트의 컬럼을 정의합니다.
- `items` 시트는 `tableHeaders_()` 로 **base 헤더 + 앱이 보낸 새 필드**를 자동 합쳐 저장합니다.
  → 앱에 새 물품 필드(예: `spec` 규격)를 추가해도 **이 스크립트를 다시 고칠 필요가 없습니다.**
  (`__` 로 시작하는 내부 전용 필드는 저장 제외)
- `load` 는 시트 헤더 이름 기준으로 읽으므로 새 컬럼도 자동으로 앱에 전달됩니다.

## 기존 학교에 반영하는 법 (코드 변경 시)
1. 학교 스프레드시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 전체를 이 파일 내용으로 교체 → **저장(Ctrl+S)**
3. **배포 → 배포 관리 → (기존 웹앱) 편집(연필) → 버전: 새 버전 → 배포**
   - 웹앱 URL(`/exec`)은 그대로 유지됩니다. 교사 접속주소도 바뀌지 않습니다.
4. 앱에서 물품을 한 번 저장하면, 그때 시트가 새 컬럼 구조로 다시 기록됩니다.
   (기존 데이터는 헤더 이름 기준으로 보존됩니다.)
