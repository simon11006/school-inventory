# 교구이음

학교의 체육실, 과학실, 컴퓨터실, 미술실, 방송실 등 **모든 물품실의 물품을 한 곳에서 예약·분출·반납·손망 처리**할 수 있는 웹앱입니다. 한 번 배포해 두면 어느 학교든 자기 Google 계정만 있으면 자기 데이터로 분리해서 사용할 수 있습니다.

운영용 Google Spreadsheet와 Apps Script는 담당자 개인 계정보다 **학교 공용 Google 계정**으로 만드는 것을 권장합니다. 개인 계정으로 만들면 담당자 변경이나 퇴직 시 소유권·배포 권한 인계가 어려워질 수 있습니다.

처음 사용하는 학교 담당자는 먼저 [`처음설정가이드.html`](./처음설정가이드.html)을 열어 1~10단계를 순서대로 따라 하세요.

---

## 한눈에 보는 시스템 구조

```
[교사 PC들의 브라우저]  ←──── 20초마다 자동 동기화 ────→  [학교의 Google Spreadsheet]
       │                                                          ↑
       │ 예약/반납하면 즉시 저장                                  │
       └──────────────────────────────────────────────────────────┘
```

- 앱 코드는 정적 파일(HTML/CSS/JS)이라 **Netlify 같은 정적 호스팅 한 곳에 한 번만 올리면** 모든 학교가 같은 주소로 접속해 사용
- 데이터는 학교마다 **각 학교의 Google Spreadsheet에 분리 저장** (학교 간 데이터 섞이지 않음)
- 같은 학교 안에서는 **20초 폴링으로 교사 간 자동 공유**

---

## 사용 가능한 기능

- 학교명·교사 목록·물품실 자유 설정
- 전체 관리자 + 물품실별 담당자 권한 분리 (담당자는 자기 물품실만 관리)
- 물품 예약 → 분출 → 반납 → 파손·분실·폐기 처리의 전체 흐름
- 엑셀 `.xlsx` / `.xls` / `.csv` 일괄 등록 (미리보기와 오류 표시)
- 사용 기록 분류 조회 (등록·예약·분출·회수·손망·설정)
- CSV 내보내기로 백업
- 인계 점검 (담당자 변경 시 확인 항목 체크리스트)
- Google Spreadsheet 자동 양방향 동기화
- 다크모드 / 라이트모드
- 외부 인터넷 연결 없이 동작하는 SheetJS (`vendor/xlsx.full.min.js`)

초기 관리자 PIN은 `1234`입니다. **운영 시작 전 반드시 학교 운영용 PIN으로 변경**하세요.

## 일반 교사 사용법

### 1. 본인 이름 선택
- 화면 오른쪽 위 **사용 교사** 드롭다운에서 본인 이름을 선택합니다.
- 이 이름이 새 예약을 만들 때 예약자로 자동 입력됩니다.

### 2. 물품실 선택
- 왼쪽 위 **물품실 선택** 드롭다운에서 사용할 물품실을 고릅니다 (체육실, 과학실 등).
- 전체 물품을 보려면 **모두**를 선택합니다.

### 3. 예약하기
- 첫 화면 **물품 사용 예약**에서 사용할 물품을 검색하거나 목록에서 찾습니다.
- 물품 옆 **예약하기** 또는 상단 **+ 새 예약**을 눌러 예약합니다.
- 수량과 사용 시작·종료일을 입력하면 예약 완료.

### 4. 사용 후 반납
- 왼쪽 메뉴 **내 예약·반납**으로 이동합니다.
- 예약 건을 선택하고 작업 패널의 **반납 처리**를 누릅니다.
- 파손·분실이 있으면 같은 화면에서 수량과 사유를 함께 입력합니다.

### 5. 화면 모드 바꾸기
- 오른쪽 위 ◐ 버튼으로 다크모드 / 라이트모드 전환.

## 관리자 사용법

### 관리자 모드 진입
1. 오른쪽 위 **관리자 모드** 버튼 클릭
2. PIN 입력 (전체 관리자: 학교 PIN / 물품실 담당자: 본인 이름 선택 후 담당자 PIN)
3. 관리자 모드에 들어가면 **사용 기록** 화면이 먼저 열림

### 학교 설정 (전체 관리자만)
- 오른쪽 위 **학교 설정** 클릭
- 학교명, 교사 목록(추가·이름변경·삭제), 물품실, 물품실별 담당자와 담당자 PIN, 전체 관리자 PIN을 모두 한 화면에서 관리
- 같은 화면 아래쪽 **저장소 연결** 섹션에서 Google Spreadsheet 연동 설정

### 물품 관리
- 왼쪽 메뉴 **물품 관리**
- **물품 추가**로 신규 물품 등록, 물품을 선택하면 **물품 수정**으로 편집
- 손망(파손·분실·폐기) 수량, 관리 번호, 단위, 구입일, 비고 등 입력 가능

### 일괄 등록
- 왼쪽 메뉴 **일괄 등록**
- **엑셀 양식 받기**로 양식 내려받기 → 채워서 업로드
- 미리보기에서 오류 행 확인 후 **미리보기대로 등록**
- **현재 물품 내보내기** / **기록 내보내기**로 CSV 백업도 가능

### 사용 기록
- 왼쪽 메뉴 **사용 기록**
- 분류 탭(등록·예약·분출·회수·손망·설정)으로 필터링
- 날짜를 지정해 특정 일자의 기록만 조회

### 예약·반납 목록
- 왼쪽 메뉴 **내 예약·반납** (관리자 모드에서는 전체 예약이 보임)
- 예약 선택 후 작업 패널에서 **분출 처리**, **반납 처리**, **손망 처리** 진행

### 인계 점검
- 오른쪽 위 **인계 점검** 클릭
- 담당자 교체 시 스프레드시트 소유자, Apps Script 배포 권한, 연결 키, 백업, 기존 담당자 권한 정리 항목을 확인

## Google Spreadsheet 연동과 실시간 공유

### 동작 방식

`관리자 모드 > 학교 설정 > 저장소 연결`에서 Apps Script 웹앱 URL과 연결 키를 입력하면 다음과 같이 동작합니다.

| 자동 동기화 모드 | 동작 |
|------------------|------|
| 수동으로만 실행 | 담당자가 **현재 데이터 올리기** / **스프레드시트에서 가져오기** 버튼을 누를 때만 동기화 |
| 앱 시작 시 원격 데이터 확인 | 앱이 켜질 때 원격이 더 새로우면 자동으로 가져옴 + 20초 폴링 |
| **저장 후 원격에 자동 올리기** (권장) | 변경마다 즉시 올림 + 20초 폴링으로 다른 PC 변경 자동 반영 |

### 폴링 동작 (실시간 공유)

자동 동기화를 켜두면 다음과 같이 동작합니다:

| 시점 | 동작 |
|------|------|
| 앱 처음 실행 | 즉시 1회 동기화 → 20초 폴링 시작 |
| 다른 탭/창으로 이동 | 폴링 일시정지 (호출 한도 절약) |
| 다시 화면으로 복귀 | 즉시 1회 동기화 → 20초 폴링 재개 |
| 화면 보고 있는 동안 | 20초마다 자동 동기화 |

다른 교사의 변경사항이 **최대 20초 안에** 내 화면에 반영됩니다.

### 동시 예약 충돌 보호

- Apps Script가 스프레드시트 마지막 저장 시각을 기록
- 클라이언트가 알고 있던 시각과 다르면 저장을 거부 → 데이터 덮어씀 방지
- 가져오기 전 로컬에 미반영된 변경이 있으면 확인 후 진행

### 학교별 사용 한도

| 계정 종류 | 일일 호출 한도 | 예상 동시 사용 교사 |
|-----------|----------------|---------------------|
| 개인 Gmail | 약 20,000회 | 약 100~300명 |
| 학교/교육청 Workspace | 약 100,000회 | 약 500~1,500명 |

대한민국 학교 규모로는 어느 쪽이든 충분합니다. 학교 단위로 한도가 분리되어 있어 다른 학교의 사용량이 영향을 주지 않습니다.

## 실행과 배포

### 개발자 / 학교 IT 담당자
- 정적 파일 한 묶음(`index.html`, `app.js`, `inventory-core.js`, `inventory-storage.js`, `styles.css`, `vendor/xlsx.full.min.js`, `처음설정가이드.html`)을 Netlify·GitHub Pages·교육청 웹서버 등에 업로드
- 학교 담당자는 `처음설정가이드.html`에 따라 마스터 스프레드시트 사본을 만든 뒤, 사본에 포함된 Apps Script를 웹앱으로 배포

### 학교 담당자 (운영자)
1. 받은 웹앱 주소를 브라우저에 입력 (또는 압축을 풀어 `index.html` 더블클릭)
2. [`처음설정가이드.html`](./처음설정가이드.html)의 1~10단계 따라 하기
3. Google Spreadsheet와 Apps Script는 가능하면 **학교 공용 Google 계정**으로 생성
4. 다른 교사들에게 웹앱 주소만 공유. 연결 키와 웹앱 URL은 **학교 내부 메신저로만** 공유

### 일반 교사
- 담당자가 알려준 웹앱 주소만 열면 됨
- 사용 교사 선택 → 물품실 선택 → 예약 / 반납

## 보안과 개인정보

- 모든 데이터는 학교가 만든 Google Spreadsheet에만 저장됩니다 (개발자는 데이터에 접근하지 않음)
- 웹앱 URL과 연결 키는 학교 데이터에 접근할 수 있는 열쇠이므로 외부에 공개하지 마세요
- 연결 키 유출이 의심되면 Apps Script에서 `setupInventorySpreadsheet`를 다시 실행해 새 연결 키를 발급받고 모든 PC의 키를 교체하세요
- 초기 관리자 PIN `1234`는 **반드시** 학교 운영용 PIN으로 변경하세요
