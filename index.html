스마트 예약
교사가 직접 물품을 검색하고 날짜를 선택해 예약합니다. 실시간 재고 현황을 확인하며 중복 예약을 방지합니다.
  • 실시간 재고 현황 확인
  • 날짜·수량 지정 예약
  • 예약 현황 한눈에 보기
🗂️
재고 관리
관리자가 물품실별로 물품을 등록하고 관리합니다. 카테고리, 수량, 상태를 체계적으로 기록합니다.
  • 물품실·카테고리별 분류
  • 물품 상태 실시간 추적
  • 엑셀 일괄 가져오기
🛒
구입 요청
필요한 물품을 교사가 직접 요청하고, 관리자가 검토·승인합니다. 구입 이력도 자동으로 기록됩니다.
  • 교사 → 관리자 요청 흐름
  • 요청 현황 및 처리 상태
  • 구입 이력 자동 기록

물품 예약, 3단계면 끝

1
물품 검색
물품실을 선택하거나 검색어를 입력해 원하는 물품을 찾습니다. 실시간 재고와 대출 현황을 바로 확인할 수 있습니다.
2
날짜·수량 선택
사용 날짜와 필요한 수량을 입력합니다. 이미 예약된 날짜는 자동으로 표시되어 중복을 방지합니다.
3
예약 완료
확인 버튼 하나로 예약이 완료됩니다. 관리자 화면에도 즉시 반영됩니다.

시작 방법

오늘 바로 시작할 수 있습니다

복잡한 설치나 설정 없이, 4단계만으로 우리 학교 교구 관리 시스템을 만드세요.

1
학교 계정 생성
이메일로 가입하고 학교 이름을 설정합니다. 1분이면 완료.
2
물품 등록
물품실을 만들고 교구를 하나씩 또는 엑셀로 한 번에 등록합니다.
3
교사 초대
초대 링크를 공유하면 교사들이 바로 접속해 예약을 시작합니다.
4
예약 시작
이제 교사들이 스스로 교구를 검색하고 예약합니다. 관리 부담이 줄어듭니다.
자주 묻는 질문

궁금한 점이 있으신가요?

학교에서 가장 많이 물어보시는 질문들을 모았습니다.

교구이음을 만든 사람이 우리 학교 데이터를 볼 수 있나요?
볼 수 없습니다. 각 학교의 물품 목록, 예약 내역, 교사 정보는 해당 학교 관리자만 접근할 수 있습니다. 교구이음 운영자는 개별 학교 데이터에 접근하지 않으며, 학교별 데이터는 완전히 독립된 공간에 저장됩니다.
다른 학교에서 우리 학교 물품 목록이나 예약 내역을 볼 수 있나요?
볼 수 없습니다. 우리 학교 페이지는 관리자가 교사들에게 공유하는 고유한 내부 주소를 통해서만 접근할 수 있습니다.

이 주소를 공유하지 않는 한, 외부인은 우리 학교 데이터에 접근할 방법이 없습니다. 주소를 알더라도 학교 계정으로 로그인하지 않으면 내용을 볼 수 없습니다.
학교 관리자는 누가 되나요? 관리자 권한은 어떻게 부여되나요?
처음 학교 계정을 생성한 분이 자동으로 학교 관리자가 됩니다. 관리자는 물품 등록·수정·삭제, 교사 초대, 구입 요청 승인 등 모든 권한을 가집니다. 일반 교사는 물품 조회와 예약만 할 수 있어, 실수로 데이터를 수정하거나 삭제할 걱정이 없습니다.
교사가 실수로 물품을 삭제하거나 데이터를 망가뜨릴 수 있나요?
그럴 수 없습니다. 물품 추가·수정·삭제는 관리자 권한이 있어야만 가능합니다. 교사는 물품을 검색하고 예약하는 것만 할 수 있어, 데이터가 의도치 않게 변경되는 상황을 구조적으로 방지합니다.
